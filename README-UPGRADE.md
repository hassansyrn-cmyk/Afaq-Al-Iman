# Afaq Al-Iman V4 Upgrade Overlay
انسخ محتويات هذه الحزمة فوق جذر المستودع مع الاستبدال، مع إبقاء مجلد public الحالي لأنه يحتوي صور التطبيق وملفات القرآن.

## ما تم تنفيذه
- WindowInsets Native لإبعاد WebView عن النوتش وشريطي النظام على Android 15/16.
- عد تنازلي في Hero للصلاة القادمة.
- Android Home Screen Widget مع Chronometer أصلي.
- نافذة شرح ثم طلب إذن الإشعارات في أول تشغيل.
- جدولة 14 يوماً للصلاة والأذكار والورد والحديث وتخزينها في Android.
- أيقونة إشعار أحادية مستوحاة من شعار آفاق، وليست علامة التعجب الافتراضية.
- إعادة مكتبة الحديث والبحث العربي والإنجليزي والحديث اليومي.
- قارئ قرآن متصل عمودياً بخط Amiri Quran محلي، وتكبير وتصغير الخط.
- Bookmark مستقل وممتلئ بعد الحفظ.
- بوصلة محسنة بتنعيم دائري وDead zone وسهم أحمر.

## حدود موثقة
- ملف hadith.ts المرفق هو المجموعة الموثقة الحالية، وليس جميع الصحيحين. إضافة جميع الصحيحين تتطلب ملفات بيانات موثقة ومرخصة.
- القارئ متصل رأسياً لكنه لا يدعي مطابقة صفحات مصحف المدينة 604 لأن Metadata الصفحات غير موجود في المشروع الحالي.
- الويدجت يحصل على الصلاة القادمة عند فتح التطبيق أو تغيير المدينة. Chronometer نفسه يستمر في العد دون تشغيل التطبيق.
