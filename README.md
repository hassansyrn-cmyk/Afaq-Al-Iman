# آفاق الإيمان v1.3
نسخة موسعة بتصميم زجاجي، وضع ليلي، ختمة مرنة، بحث الأحاديث، قرآن محلي كامل، علامات مرجعية وإعدادات إشعارات.

## مصدر القرآن
النص المحلي مأخوذ من Tanzil عبر حزمة quran-json. يجب الإبقاء على نسبة المصدر والرابط إلى Tanzil عند النشر، وعدم تعديل النص القرآني.

## ملاحظات
- قسم الأحاديث في هذه النسخة مجموعة مختارة موثقة وقابلة للبحث، وليس قاعدة الصحيحين الكاملة بعد.
- التفسير وأسباب النزول غير مولدة آلياً. الواجهة جاهزة لمصدر تفسير معتمد لاحقاً.
- إشعارات الصلاة في هذه النسخة التجريبية مجدولة لأبوظبي، ويلزم دمجها مع المدينة المختارة من النسخة السابقة قبل النشر العالمي.
