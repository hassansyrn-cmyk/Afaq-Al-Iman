# Afaq Al-Iman reliability and language update
انسخ محتويات هذا المجلد فوق جذر الريبو مع الاستبدال.

الإصلاحات:
- انتقال الصلاة والعداد تلقائياً للصلاة التالية داخل التطبيق والويدجت.
- إرسال جدول 3 أيام للويدجت مع AlarmManager لتحديثه بعد موعد الصلاة.
- فحص إذن الإشعارات والتنبيهات الدقيقة، اختبار خلال 5 ثوانٍ، وتخصيص الأنواع والتذكير المبكر والصوت والاهتزاز.
- زر رجوع الهاتف داخل السورة يعود أولاً لقائمة السور.
- إعادة العربية والإنجليزية مع RTL/LTR ومفتاح لغة في الهيدر والإعدادات.
- استخدام public/icon.png في الهيدر بدل حرف الألف.

بعد النسخ شغّل:
npm run build
npx cap sync android
ثم ارفع الملفات إلى main.
